## About the Project

This repository contains the **landing page** built with **React + Vite + Tailwind CSS**, showcasing the app's vision, features, prototype, and call-to-action for early wishlist sign-ups.

The site is specifically made for 1920 x 90 size displays, performant, and designed with a clean, modern aesthetic using custom fonts (`Lateef` for the brand name, `Stack Sans Text` for body copy) and subtle glassmorphism effects.

### Key Sections
- **Hero** – Bold headline with store badges and social proof
- **About** – Mission and core values
- **How It Works** – Step-by-step animated cards
- **Features** – Highlighted key functionalities
- **App Launch CTA** – Wishlist signup form
- **Prototype** – Interactive mockup showcase
- **Blog Insights**, **Admin Dashboard Preview**, **Footer**

## Tech Stack

- **React 18** with TypeScript
- **Vite** – fast development server and build tool
- **Tailwind CSS** – utility-first styling
- **Lucide React** – icons
- **shadcn/ui** components (Button, etc.)
- **React Router** (ready for future pages)

## Setup & Installation

- Node.js (v18 or higher recommended)
- npm, yarn, or pnpm
